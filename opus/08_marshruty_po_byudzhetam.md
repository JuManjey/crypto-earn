# 08. Маршруты по бюджетам

Принцип: не распределять весь доступный капитал автоматически. Если сумма слишком мала для разумной экономики после комиссий, это сказано прямо. Цифры — снимок на 2026-11-08 (ETH $2,237).

## Сначала главное: два подхода в цифрах

**Подход 1 — доходность на небольшой капитал:**

| Капитал | При 4% годовых (как sUSDS или ОВДП) | В месяц |
|---|---|---|
| $500 | $20 в год | $1.7 |
| $2,000 | $80 в год | $6.7 |
| $10,000 | $400 в год | $33 |
| $50,000 | $2,000 в год | $167 |

**Подход 2 — навыки → денежный поток → капитал:**

| Часов в месяц | По $25 в час | По $40 в час |
|---|---|---|
| 20 | $500 | $800 |
| 40 | $1,000 | $1,600 |
| 80 | $2,000 | $3,200 |

**Когда второй подход экономически лучше:** 40 часов в месяц по $25 дают столько же, сколько $245k капитала при чистых 5% или $405k при 3% ([расчёт](04_metodika_i_raschety.md#3-навыки-против-капитала)). Пока ваш капитал меньше нескольких сотен тысяч долларов, каждый час на навыки и клиентов даёт больше, чем оптимизация ставки. Капитальные направления на суммах до $10k имеют смысл как сохранение денег или как обучение, а не как источник дохода.

## Бюджет $0–100

**Честно о сумме:** доходность на $100 равна $2–5 в год. Деньги здесь нужны только для отработки механики.

### 1A. «Навыки → первые деньги» (основной маршрут)

| Параметр | Значение |
|---|---|
| Стартовый капитал | $0 |
| Резерв на расходы | $0–30 (домен, по желанию VPS) |
| Невозвратные затраты | ≤ $30 |
| Сумма под риском | $0 |
| Время | 15–20 часов в неделю первые 4 недели, затем 10 |
| Этапы | неделя 1 — нода Hoodi ([T1](06_tech/T1_hoodi_csm_validator/README.md)) на домашнем ПК; неделя 2 — мониторинг ([T2](06_tech/T2_monitoring/README.md)); неделя 3 — публичный репозиторий, резюме, профиль; недели 3–12 — 10–15 откликов в неделю ([K01](03_kartochki/K01_devops_rabota_kontrakty.md)) и 10 разговоров с операторами ([K02](03_kartochki/K02_uslugi_nody_monitoring.md)) |
| Первая проверка | день 30: ≥40 откликов, ≥2 интервью, ≥10 разговоров |
| Критерий успеха | к дню 90 — оффер или оплаченный контракт или пилот |
| Критерий остановки | день 60 без интервью — менять позиционирование, а не продолжать |
| Выход | не требуется (капитала нет) |

### 1B. «Конкурсы как воронка найма»

| Параметр | Значение |
|---|---|
| Капитал | $0 (возможен возвратный депозит ETH) |
| Время | 30–50 часов на событие, не чаще 1–2 событий в квартал |
| Этапы | Arbitrum Open House Online Buildathon (16.11–06.12.2026) с инфраструктурным проектом; 2 глобальных баунти в месяц на Superteam Earn ([K05](03_kartochki/K05_hakatony_baunti_granty.md)) |
| Первая проверка | после первого события |
| Успех | приз или хотя бы одно интервью или пилот |
| Остановка | два события подряд без результата |

### 1C. «Операционный тренажёр» на $50–100

| Параметр | Значение |
|---|---|
| Капитал | $50–100 |
| Невозвратные затраты | спреды и газ ≈ $2–5 |
| Под риском | $50–100 |
| Этапы | гривна → USDT через P2P → собственный кошелёк → sUSDS на L2 или CEX Earn → обратно в гривну; каждую операцию записать в [ledger.py](06_tech/T3_tools/README.md) |
| Первая проверка | после полного цикла (1–2 недели) |
| Успех | цикл задокументирован, фактическая стоимость конвертации в процентах известна |
| Остановка | стоимость цикла больше 3% — не масштабировать стейблкоин-стратегии |
| Выход | вывод в гривну через P2P |

## Бюджет $100–500

**Честно о сумме:** $500 при 4% дают $20 в год. Сохраните капитал и вкладывайте время.

### 2A. Навыки + MVP продукта

| Параметр | Значение |
|---|---|
| Капитал | $0 |
| Резерв | $50–100 (VPS на 3 месяца, домен) |
| Невозвратные | $50–100 |
| Под риском | $0 |
| Время | 40–80 часов разработки + 20 интервью |
| Этапы | маршрут 1A + проверка спроса на мониторинг ([K03](03_kartochki/K03_produkt_monitoring_validatorov.md)): интервью → лендинг с предоплатой → MVP на базе T2 |
| Первая проверка | после 20 интервью (день 30–45) |
| Успех | 5 предоплаченных пилотов к дню 90 |
| Остановка | меньше 2 согласий на пилот после 20 интервью |
| Выход | закрыть сервис, оставить open-source |

### 2B. Сохранение капитала

| Параметр | Значение |
|---|---|
| Капитал | $300–500 |
| Решение | долларовые ОВДП (3.6–4.1%, без налога) или просто доллары; в крипту — не больше $100 на маршрут 1C |
| Невозвратные | спред банка или брокера |
| Успех | капитал сохранён до момента, когда появится денежный поток для серьёзных решений |

### 2C. Валидатор Gnosis как платное обучение на mainnet (не рекомендую при наличии Hoodi)

| Параметр | Значение |
|---|---|
| Капитал | 1 GNO ≈ $111–136 |
| Резерв | VPS $40–60 в месяц (дома — около $3) |
| Ожидаемый итог | убыток $100–250 за 90 дней (награды ≈ $4) |
| Почему вообще упоминается | реальный mainnet со slashing на минимальной сумме; срок жизни — до весны 2027 ([CoinScreamer](https://coinscreamer.com/gnosis-chain-eez-ethereum-transition-spring-2027/)) |
| Выход | разлок GNO при переходе Gnosis в EEZ |

## Бюджет $500–2,000

**Честно о сумме:** $2,000 при 4–5% дают $80–100 в год. Капитал — подушка и будущий залог, а не источник дохода.

### 3A. Услуги для первых клиентов (основной)

| Параметр | Значение |
|---|---|
| Капитал | $0–200 (сервер мониторинга, инструменты) |
| Время | 10–20 часов в неделю |
| Этапы | пакеты услуг, договор и SLA, 20 разговоров, 1–3 пилота ([K02](03_kartochki/K02_uslugi_nody_monitoring.md)) |
| Первая проверка | день 45: ≥1 пилот |
| Успех | день 90: 2 клиента на сопровождении (≈ $500 в месяц по модели) |
| Остановка | больше 20 часов на привлечение одного клиента |

### 3B. Капитал как резерв

| Параметр | Значение |
|---|---|
| Капитал | $1,000–1,500 |
| Решение | долларовая часть — в ОВДП или sUSDS (сравнить после налога и конвертации, [K09](03_kartochki/K09_steyblkoiny_lending_rwa.md)); по желанию DCA в ETH для будущего залога CSM (это накопление, а не доход) |
| Под риском | вся сумма в крипте |
| Выход | ОВДП — до погашения или продажа брокеру; sUSDS — в любой момент |

### 3C. Эксперимент с повышенным риском (по желанию)

| Параметр | Значение |
|---|---|
| Капитал | $500 |
| Варианты | HLP ([K12](03_kartochki/K12_hlp_derivativnye_vaults.md)) или sUSDe ([K09](03_kartochki/K09_steyblkoiny_lending_rwa.md)) на 60 дней |
| Ожидаемый результат | порядка ±$5–15; цель — проверка механики и дисциплины выхода |
| Остановка | просадка больше 3% или результат хуже sUSDS |

## Бюджет $2,000–10,000

### 4A. Lido CSM: 1–2 ключа на mainnet (только если ETH вы держите в любом случае)

| Параметр | Значение |
|---|---|
| Капитал | ICS: 1.5 ETH (~$3,356) за 1 ключ, 2.8 ETH за 2; permissionless: 2.4 ETH (~$5,369) |
| Резерв | железо ~$1,400 + ИБП, электричество около $8 в месяц |
| Невозвратные | железо (остаточная стоимость не гарантирована) |
| Под риском | залог (цена ETH; потери из залога) |
| Время | 16–30 часов на запуск, 3–6 часов в месяц |
| Этапы | 30 дней на Hoodi с эффективностью ≥95% → заявка ICS → железо → 1 ключ mainnet → оценка через 90 дней ([K07](03_kartochki/K07_lido_csm_operator.md)) |
| Ожидаемый итог | первый год на $350–460 хуже stETH при 1 ключе: это плата за опыт; безубыточность с 6 ключей ICS |
| Первая проверка | 30 дней после активации |
| Успех | эффективность выше порога, ноль штрафов, отработанные обновления |
| Остановка | страйк, длительные отключения без резерва |
| Выход | добровольный выход, затем вывод, затем возврат залога |

### 4B. Cash-and-carry

| Параметр | Значение |
|---|---|
| Капитал | $2,000–5,000 номинала + 50% маржи |
| Невозвратные | комиссии ~0.31% номинала |
| Под риском | вся сумма (биржа, ликвидация) |
| Время | 10–30 часов на мониторинг, 4–10 часов в месяц |
| Этапы | одна биржа, обе ноги, изолированная маржа, read-only мониторинг ([K10](03_kartochki/K10_funding_basis_carry.md)) |
| Первая проверка | день 30 |
| Успех | больше 3% годовых на капитал после всех комиссий |
| Остановка | 7-дневный средний фандинг ниже 0.0035% за 8 часов |
| Выход | закрыть обе ноги, вывести |

### 4C. Пассивное ядро

| Параметр | Значение |
|---|---|
| Капитал | остаток |
| Решение | долларовая часть — ОВДП или sUSDS; ETH-часть (если нужна) — stETH ([K08](03_kartochki/K08_liquid_staking_i_delegirovanie.md)) |
| Ожидание | ≈ 3.5–4% на долларовую часть; ETH-часть определяется ценой ETH |

## Бюджет $10,000–50,000

### 5A. Масштабирование CSM (только после успеха 4A)

| Параметр | Значение |
|---|---|
| Капитал | ICS 6–16 ключей: 8–21 ETH (~$18–47k) |
| Ожидание | +$0 … +$1,100 в год сверх stETH (домашнее железо); после стоимости времени при $25 в час — около нуля |
| Время | 4–8 часов в месяц |
| Остановка | любое ухудшение условий модуля или необеспеченная резервная связь |

### 5B. Бизнес услуг

| Параметр | Значение |
|---|---|
| Капитал | $500–2,000 (мониторинг, инструменты, юрист для шаблона договора) |
| Цель | 5–10 клиентов на сопровождении (по модели $1,250–2,500 в месяц выручки) |
| Риск | дежурства: с 10+ клиентами нужен партнёр |

### 5C. Пассивное распределение

| Параметр | Значение |
|---|---|
| Решение | доллары — ОВДП (без налога) или sUSDS; ETH — stETH; LP и HLP — не больше 5% как эксперимент |
| Чего не делать | плечо, looping, points-фарминг, токенсейлы |

| Параметр | Значение |
